How the pipeline works

Designed to reflect the way meaningful data products are built: pull from the source, validate the data, standardize the columns, summarize the signal, and publish a report that is easy to understand.

01

Source

FEMA OpenFEMA publishes declaration summaries in a public JSON API. The job pulls the latest records on a regular cadence.

02

Extract

The script requests the newest records and captures the critical fields needed for analysis: state, declaration date, event type, title, and disaster number.

03

Validate

Required identifiers and timestamps are checked before the row is accepted. Duplicate or incomplete records are filtered out.

04

Transform

Rows are normalized into a clean dataset, with consistent naming and summary metrics suitable for reporting and trend analysis.

05

Load

The cleaned output is saved as a static JSON summary that can be consumed by a lightweight dashboard or reporting page.

06

Publish

The page reads the generated data and presents the latest view in a polished, readable dashboard for a portfolio audience.
