How the pipeline works

Six steps run every morning: pull from the source, validate, standardize, summarize, and publish a report that is easy to read.

01

Source

FEMA's public OpenFEMA REST API publishes Disaster Declarations Summaries, covering every federal declaration since 1953.

02

Extract

A daily Python job pages through the full declaration history, 1,000 records at a time, requesting only the fields it needs. Failed requests are retried.

03

Validate

Required identifiers and timestamps are checked before the row is accepted. Duplicate or incomplete records are filtered out.

04

Transform

Text is trimmed and standardized, missing incident types get clear defaults, and declarations are totaled by state, incident type and year.

05

Load

The result is written to a compact JSON summary: the totals plus the 20 most recent declarations, small enough to load instantly.

06

Publish

Each morning the site is rebuilt with the fresh summary and this page draws the charts and tables. If FEMA's API is down, the last good copy stays live.
